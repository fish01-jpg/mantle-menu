Server Tiers

Tiers control how much server data each account can use. Every account starts on Free. The owner can upgrade anyone at any time, and every allowance resets each day.

Default
Free
Everyone starts here
  • ✓150 chat messages a day
  • ✓500 server reads a day (loading chats, profiles, lists)
  • ✓100 server writes a day (messages, reactions, profile saves)
  • ✓5 game fetches a day (each time a game loads from our servers / GitHub)
  • ✓1 profile sync a day
  • ✓Full access to the arcade and chat

A note from the owner

Hey — real talk about why this page exists. I want to keep the servers free for everyone, but the servers cost money and some people talk a lot, which uses a lot of data and makes me pay a little bit to keep it all running.

So this is just a test: basic use stays completely free, and if you blow past the Free limits every day, the Pro tier is there for the heavy users. Nothing is set in stone — this is a beta, and the numbers may change as I see how it goes.

How it works (BETA)

When you send a chat message, Sp1der checks your tier's daily allowance and counts the message toward it. The same idea applies to server reads, server writes and game fetches — each one counts toward your tier's daily amount. If you hit a limit you'll see a notice telling you your allowance resets tomorrow — nothing breaks, it just waits.

Tiers are set by the owner with the command /tier @user — for example /tier @fish01-jpg pro. To check or change your own tier, ask an owner.

This page is a beta: the numbers above are the current limits and they may be tuned as we see how much server data the community actually uses.
