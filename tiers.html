Server Tiers

Tiers control how much server data each account can use. Every account starts on Free. The owner can upgrade anyone at any time, and every allowance resets each day.

Default
Free
Everyone starts here
  • ✓150 chat messages a day
  • ✓1 profile sync a day
  • ✓Full access to the arcade and chat
Pro
For regulars
  • ✓600 chat messages a day
  • ✓3 profile syncs a day
  • ✓Full access to the arcade and chat
Ultra
For staff and power users
  • ✓Unlimited chat messages
  • ✓10 profile syncs a day
  • ✓Full access to the arcade and chat

How it works (BETA)

When you send a chat message, Sp1der checks your tier's daily allowance and counts the message toward it. If you hit the limit you'll see a notice telling you your allowance resets tomorrow — nothing breaks, chat just waits.

Tiers are set by the owner with the command /tier @user — for example /tier @fish01-jpg pro. To check or change your own tier, ask an owner.

This page is a beta: the numbers above are the current limits and they may be tuned as we see how much server data the community actually uses.
